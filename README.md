# opencode-memory-agent

Initial OpenCode-first research and scaffolding for an always-on memory agent plugin.

## What is in this repository?

- an Astro Starlight documentation site,
- an example OpenCode project template with local agents and a debounced plugin,
- CI and GitHub Pages workflows for validating and publishing the docs.

## Quick start

```bash
npm install
npx playwright install --with-deps chromium
npm run dev
```

## Example template

See `examples/project-template/` for the initial OpenCode-oriented template files.

## Documentation

The docs site covers:

- OpenCode equivalents for the Gemini always-on memory agent,
- Bun-forward plugin development and npm installation,
- config layering for global and project use,
- storage and secret-handling recommendations,
- CI/CD and GitHub Pages publishing.
