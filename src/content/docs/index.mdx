## What is included

<CardGrid stagger>
  <Card title="Installable npm plugin" icon="package">
    The root package now exports a real OpenCode plugin entrypoint that can be referenced by package
    name in `opencode.json`.
  </Card>
  <Card title="Memory + backlog tools" icon="list-tree">
    The plugin captures session memory on idle, runs periodic consolidation, exposes
    `memory_status`, `memory_backfill`, `memory_consolidate`, `memory_query`, and
    `memory_refresh_docs`, and persists state in `.opencode/memory/`.
  </Card>
  <Card title="Project docs indexing" icon="open-book">
    Common documentation files such as `README.md`, `AGENTS.md`, and `docs/**/*.mdx` are indexed
    for later memory queries.
  </Card>
  <Card title="Docs site + GitHub Pages" icon="earth">
    This repository still publishes its documentation with Astro Starlight and build-time Mermaid
    SVG rendering.
  </Card>
</CardGrid>
